# Peercord

Privacy-focused peer-to-peer Discord alternative.

- `Peercord.html`: the app (client and host in one file). Rename to `index.html` for Electron or Capacitor builds.
- `server/`: optional dedicated server for a home lab (Windows, Linux, Raspberry Pi, Termux). See `server/README.md`.
- `.github/workflows/server.yml`: builds the server executables.
